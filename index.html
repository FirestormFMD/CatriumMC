Core Technology

Mixin Framework

Uses SpongePowered Mixin to inject into Minecraft classes at load time. Composable, maintainable, and update-friendly — the industry standard for mod compatibility.

ASM CoreMod API

Direct bytecode manipulation via ObjectWeb ASM gives advanced modders the raw access they need. Write transformation visitors that run before class loading for zero-cost hooks.

Fabric Interop Layer

CatriumMC ships with a built-in compatibility shim for the Fabric mod API, so the thousands of existing Fabric mods load natively alongside CatriumMC-native mods.

Get Started

1

Download the Installer

Grab the latest CatriumMC installer JAR from the releases page.

Download Installer
2

Run the Installer

Execute the JAR with Java 17+ and select your Minecraft installation directory.

java -jar catriummc-installer.jar
3

Add Your Mods

Drop CatriumMC-native or Fabric mods into your mods/ folder and launch Minecraft.
